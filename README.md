# Dad Joke Showdown

One dad joke (≤200 characters), told out loud.

> I told my suitcase there would be no vacation this year. Now I'm dealing with emotional baggage.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
